Tickets
POST /tickets required title: string (max 255)
required customerName: string
required customerEmail: email
required description: string
optional priority: LOW | MEDIUM | HIGH 		201 Ticket created, status = OPEN
400 Validation error 		Public
GET /tickets optional ?status= OPEN | IN_PROGRESS | RESOLVED | CLOSED
optional ?q= keyword search (title, name, email)
optional ?includeDeleted= true | false 		200 Array of tickets (createdAt DESC)
401 Missing or invalid token 		🔒 Admin
GET /tickets/:id required id: uuid (path param) 200 Single ticket object
400 Invalid UUID format
401 Missing or invalid token
404 Not found or soft-deleted 		🔒 Admin
PUT /tickets/:id/status required status: OPEN | IN_PROGRESS | RESOLVED | CLOSED

Valid transitions: OPEN → IN_PROGRESS → RESOLVED
CLOSED is cron-only — returns 400 if requested via API 		200 Updated ticket, resolvedAt set if → RESOLVED
400 Invalid transition or CLOSED requested
401 Missing or invalid token
404 Not found 		🔒 Admin
DELETE /tickets/:id required id: uuid (path param) 200 Ticket with deletedAt + deletedBy set
(row is kept in DB — soft delete)
401 Missing or invalid token
404 Not found or already deleted 		🔒 Admin
